# 数据备份与迁移

EO2Weave 的所有数据（项目、对话、文件、API 密钥、应用设置）都存储在浏览器本地的 OPFS 中，**不会自动上云同步**。数据绑定「域名 + 浏览器」——换电脑、换浏览器、或从旧地址迁移到新域名（如 weave.eo2suite.cn）时，需要通过导出 / 导入备份来完成迁移。

## 备份包含什么

| 内容 | 说明 |
|------|------|
| SQLite 数据库 | 项目、对话记录、工作区元数据、加密后的 API 密钥 |
| 工作区文件 | 各项目工作区里的全部文件 |
| 设备加密密钥 | 让 API 密钥在导入后仍可解密使用 |
| 应用设置 | 主题、语言、模型配置、输入历史等 |

## 导出备份

1. 打开应用**首页**（项目列表页）
2. 在左侧边栏找到**「高级」**折叠面板（默认收起，标注有"重置、备份、缓存清理等"），点击展开
3. 在**「数据备份」**卡片中点击**「导出」**
4. 弹出确认对话框，提示备份文件包含加密密钥与登录凭据——点击**「导出备份」**确认
5. 等待片刻（按钮变为"正在备份…"），浏览器会自动下载一个形如 `eo2weave-backup_2026-08-20_14-30-00.zip` 的文件
6. **妥善保管该文件**：它等同于完整的账户访问权限（含 API 密钥），不要分享给他人或放入公共存储

> 💡 导入前如果提示"建议先导出一份当前备份"，就是用这个功能。建议养成定期导出的习惯。

## 导入备份（恢复 / 迁移到新设备）

1. 在新设备 / 新浏览器打开 EO2Weave，进入**首页**
2. 左侧边栏展开**「高级」** → **「数据备份」**卡片 → 点击**「导入」**
3. 在文件选择器中选中之前导出的 `.zip` 备份文件
4. 确认对话框会警告：**导入会清空当前全部数据（项目、对话、文件），并用备份内容完全替换**
5. 点击**「覆盖并恢复」**，等待"正在恢复…"完成，页面会自动刷新
6. 刷新后所有项目、对话、文件、API 密钥和设置都会恢复到导出时的状态

## 注意事项

- **导入是全量替换，不是合并**：当前设备上的所有数据会被备份内容覆盖。如果目标设备上也有重要数据，请先导出一份再导入。
- **只接受本应用导出的 zip**：导入前会校验备份中必须包含 SQLite 数据库文件，随意选一个 zip 会直接报错，不会破坏现有数据。
- **关闭其他标签页**：如果同一浏览器还开着其他 EO2Weave 标签页，数据库文件会被锁定导致导入失败，按提示关闭其他标签页后重试。
- **跨域名迁移**：从旧地址迁移到 weave.eo2suite.cn（或将来换域名）同样用这套导出 / 导入流程，因为不同域名的 OPFS 存储相互隔离。
- **备份文件保密**：备份包含加密密钥、API 密钥和登录凭据，拿到文件的人可以完整恢复你的账户访问权限。
