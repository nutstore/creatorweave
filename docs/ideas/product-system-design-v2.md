# CreatorWeave 产品体系设计（v2）

> 基于 2026-08-03 完整代码探查 + 《一人公司》《纳瓦尔宝典》框架 + 产品讨论。
> 核心修正：加入双形态、草稿层信任模型、Skill 完整度分层。

---

## 一、产品本质（一句话）

> **浏览器原生的 AI 工作台——两种形态覆盖"深度工作"和"即时辅助"，靠技能（Skill）完成完整工作，AI 改动先进 OPFS 草稿层、用户审批后才同步磁盘，数据全程本地不离开浏览器。**

## 二、四大支柱（缺一不可）

| 支柱 | 作用 | 没有它会怎样 |
|------|------|-------------|
| **浏览器原生 + 双形态** | 零安装；独立模式做深度工作，side panel 做即时辅助 | 回到"又一个 IDE/编辑器"的红海 |
| **技能体系（Skill）** | 把"完整工作流"固化成可复用、可分发的包 | 沦为通用 AI 对话工具，没有壁垒 |
| **OPFS 草稿层 + 审批同步** | AI 改动可审查、可撤销、用户掌控 | 用户不敢让 AI 动重要文件（信任鸿沟） |
| **Page Action + WebMCP** | 连接外部网页世界，操控/调用网站能力 | 封闭在本地，无法和在线工作流联动 |

## 三、三层产品体系

### 第一层：工作台基座（免费）

**定位：让用户体验到"浏览器里的 AI 真的能干活"的 Wow 时刻。**

```
浏览器 AI 对话（多模型）
  + 文件读写（File System Access API）
  + 浏览器内 Python（Pyodide）
  + 浏览器扩展（web_search / web_fetch / page action 基础能力）
  + OPFS 草稿层 + 审批工作流
  + 3-4 个基础 Skill
```

**KPI：用户第一次"Wow"。** 用户必须在这里感受到"自然语言驱动 + 本地文件 + 草稿审批"的组合体验。

**设计要点：基础能力够用但不满足。** 让用户装 Skill 后体验明显升级——自然引导到第二层。

### 第二层：技能生态（核心价值层 / 护城河）

**定位：这里是与所有竞品拉开差距的地方。**

**类型 A：官方精品 Skill（团队核心产出）**

| 方向 | Skill | 为什么是壁垒 |
|------|-------|------------|
| 文档深度编辑 | cw-word-editor（89 EditOps） | 没有竞品做到这个深度 |
| 数据分析 | cw-data-analyst（待建） | Pyodide 全套已就绪，缺工作流封装 |
| 前端开发 | cw-impeccable-design + cw-code-review | 程序员高频刚需 |
| 网页自动化 | 基于特定网站的 WebMCP 适配 | 覆盖高频网站工作流 |

**类型 B：社区 Skill（生态广度）**

- 用户自建，ZIP 分享
- 当前缺：Skill 目录站（发现机制）+ 质量标准

**类型 C：项目级 Skill（B2B 入口）**

- 存 `.skills/` 随 Git 共享
- 企业内部工作流固化

### 第三层：专业场景方案（变现层）

**定位：用户为"放心自动化"付费。**

| 方案 | 核心承诺 | 面向 |
|------|---------|------|
| **文档自动化** | AI 生成/编辑 Word，草稿审批后同步本地 | 行政/文员/律师 |
| **代码自动化** | AI 重构/批量改代码，diff 审批后同步 | 开发者/小团队 |
| **数据自动化** | AI 处理数据生成报表，预览后同步 | 数据分析师 |
| **网页自动化** | AI 操作高频网站，完成多步任务 | 运营/客服 |

**共同主题：用户为"放心"付费。** 草稿层让 AI 从"好用但不敢用"变成"好用且敢用"。

## 四、双形态下的 Skill 设计原则

每个 Skill 在设计时都要考虑两种形态：

| | 独立模式（深度） | Side panel 模式（即时） |
|--|----------------|---------------------|
| 文档编辑 | 全屏编辑器 + 89 EditOps | 看着文档时 AI 在旁辅助 |
| 数据分析 | 全屏跑 Python + 生成图表 | 读当前页面表格 → 分析 |
| 网页自动化 | 给 URL，AI fetch 处理 | 直接操作当前绑定的 tab |
| WebMCP | 描述任务，AI 调工具 | 直接操作当前打开的网站 |

## 五、与两本书的交叉映射

**纳瓦尔的底层逻辑（为什么值）：**
- 杠杆：Skill = 代码/媒体杠杆（无需许可，做一次 N 人用）
- 专长：你们在文档编辑深度（89 EditOps）上的积累是专长
- 复利：Skill 越多越值钱（生态网络效应）
- 判断力：选准 3 个杀手级 Skill 做，比铺 20 个重要

**一人公司的操作框架（怎么干）：**
- 流量：Skill 商店 = 发现机制 = 第一批用户从哪来
- 产品：Skill = 把能力变成可复制的产品
- 营销：精品 Skill 本身就是最好的内容（"看，AI 这样帮我改 Word"）
- 生态：Skill 社区 = 合作十倍放大
